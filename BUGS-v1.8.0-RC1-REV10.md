# Bugs / limites connus - v1.8.0 RC1 Rev.10

- Les données libres créées par l'association (noms de projets, commentaires, notes, etc.) restent dans leur langue d'origine, volontairement.
- Les longues descriptions botaniques historiques ne sont pas traduites automatiquement ; les libellés système et la navigation utilisent le nouveau mécanisme d'internationalisation.
- Pour les espèces sans nom commun anglais renseigné, le nom scientifique est utilisé comme valeur de repli.
- Les tests de rendu RTL et de filtrage des listes sur Safari iOS / Chrome Android doivent être validés sur appareils réels.
