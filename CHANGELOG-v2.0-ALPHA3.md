# MyTree Professional v2.0 Alpha 3 — Online Test

## Carte et arbres
- Politique v2.0 Alpha 3 : tous les arbres validés sont visibles globalement, individuels comme associatifs.
- Filtres rapides : Tous, Mes arbres, Individuels, Associations, À arroser.
- Panneau « Plus de filtres » responsive avec Appliquer / Réinitialiser.
- Même query-string entre Liste et Carte afin de conserver les filtres.
- Filtres : type, association, bénévole, wilaya, commune, projet, zone, espèce, santé, arrosage.
- Marqueur arbre 🌳 pour les individus et symbole propre à l'association pour les arbres associatifs.
- Popup carte indiquant l'origine (association ou bénévole).
