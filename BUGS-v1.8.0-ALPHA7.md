# Bugs et limites connus — MyTree Professional v1.8.0 Alpha 7

- Le référentiel contient les 58 wilayas, mais la liste exhaustive des 1 541 communes n’est pas encore intégrée. Les communes déjà enregistrées restent utilisables et l’API dynamique par wilaya est conservée.
- Les recommandations sont une aide au filtrage fondée sur les données de la fiche botanique. Elles ne remplacent pas une étude agronomique ou forestière locale.
- Les photos sont encore gérées par URL ; le stockage local et le téléversement de fichiers restent à développer.
- Les tests HTTP automatisés doivent être rejoués dans un environnement où Flask est installé.
