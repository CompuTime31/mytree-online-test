# Bugs et limites connus — v1.8.0 Alpha 5

- La carte publique utilise OpenStreetMap et nécessite une connexion internet pour charger les tuiles.
- La caméra et la géolocalisation peuvent être bloquées par le navigateur si l’application est ouverte en HTTP depuis un téléphone ; HTTPS est recommandé.
- Les formulaires de don, d’adhésion et de matériel réutilisent encore les modules existants ; leur parcours public complet sera consolidé dans un sprint ultérieur.
- Les tests visuels sur plusieurs tailles de téléphone et tablette restent à réaliser sur appareils réels.
