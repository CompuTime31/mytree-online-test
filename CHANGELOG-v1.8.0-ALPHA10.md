# MyTree Professional v1.8.0 Alpha 10

## Interface mobile
- Accueil bénévole reconstruit avec une liste verticale de grandes actions.
- Une action ouvre une page distincte ; aucun contenu fonctionnel ne se déplie sous les boutons d’accueil.
- Bouton Retour visible dans l’en-tête mobile.
- Barre inférieure limitée à cinq accès essentiels : Accueil, Scanner, Carte, Alertes et Profil.
- Les fonctions secondaires restent disponibles dans l’accueil vertical et dans la navigation complète sur ordinateur.
- Séparation plus nette entre espace bénévole privé et accueil public.

## Sauvegarde et restauration
- Nouvelle page Administration > Sauvegarde.
- Téléchargement cohérent de la base SQLite avec l’API de sauvegarde SQLite.
- Contrôle d’intégrité avant restauration.
- Vérification des tables essentielles avant acceptation d’une sauvegarde.
- Copie automatique de l’ancienne base avant toute restauration.

## Consolidation
- Version affichée mise à jour dans l’application.
- Navigation mobile simplifiée afin d’éviter les longues listes placées au-dessus du contenu.
- Conservation des fonctionnalités et migrations des versions précédentes.
