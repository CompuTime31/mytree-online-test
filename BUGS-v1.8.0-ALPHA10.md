# Suivi des anomalies — MyTree Professional v1.8.0 Alpha 10

## Corrigé
- Navigation bénévole mobile trop longue et affichée avant le contenu.
- Boutons d’accueil qui donnaient l’impression d’ouvrir le contenu plus bas dans la même page.
- Absence d’un retour mobile permanent.
- Lien Administration > Sauvegarde sans module fonctionnel associé.

## À valider sur appareil réel
- Rendu exact de la barre inférieure selon le navigateur mobile.
- Comportement du bouton Retour après un enregistrement ou une redirection.
- Restauration d’une sauvegarde avec une base issue d’une installation antérieure.
- Performances avec une base contenant plusieurs milliers d’arbres.
