# Bugs et limites connus — v1.8.0 Alpha 6

- Le référentiel contient les 58 wilayas, mais la liste exhaustive de toutes les communes algériennes doit encore être vérifiée et complétée avant la version stable. Les communes d’Oran restent préchargées.
- Les tests réels caméra, GPS et responsive doivent être effectués sur téléphone et tablette.
- Les tests d’exécution Flask n’ont pas pu être lancés dans l’environnement de construction, car les dépendances Flask ne sont pas disponibles hors connexion.
- Une sauvegarde de la base `mytree.db` reste recommandée avant toute mise à jour.
