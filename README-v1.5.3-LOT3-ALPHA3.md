# MyTree Professional v1.5.3 — Lot 3 Alpha 3

## Lancement sous Windows

1. Extraire complètement le ZIP.
2. Ouvrir le dossier extrait.
3. Double-cliquer sur `run-windows.bat`.
4. Laisser la fenêtre noire ouverte.
5. Ouvrir `http://localhost:8080`.

Compte initial : `admin` / `admin123`.

Ne pas utiliser `python -m http.server 8080` : MyTree est une application Flask, pas un simple site statique.
