# Tests Alpha 4 — Lot 10 — Parité PC ↔ téléphone

## Navigation
- [ ] Connexion téléphone : aucune interface publique après authentification.
- [ ] Mon accueil : aucune flèche Retour.
- [ ] Mon accueil et Déconnexion accessibles.
- [ ] Déconnexion : retour vers /public.
- [ ] Changement Personnel/Association utilisable sur petit écran.

## Parité croisée
Pour Arbre, Plantation, Arrosage, Mission, Événement, Intervention, Notification :
- [ ] PC crée → téléphone consulte.
- [ ] Téléphone crée/modifie → PC vérifie.
- [ ] Même permission refusée sur PC et téléphone.

## Terrain
- [ ] Carte tactile et GPS.
- [ ] Sélection de position sur carte.
- [ ] Prendre une photo avec caméra.
- [ ] Choisir/remplacer/supprimer une photo.
- [ ] Scanner QR depuis téléphone.

## UX
- [ ] Aucun débordement horizontal global.
- [ ] Tableaux défilent dans leur conteneur.
- [ ] Boutons tactiles >= 44 px.
- [ ] Filtres communs utilisables.
- [ ] Double clic ne crée pas deux enregistrements.
- [ ] Compteur notifications inchangé à la simple ouverture de la liste.
