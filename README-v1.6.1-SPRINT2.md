# Installation Windows

1. Extraire complètement le ZIP.
2. Double-cliquer sur `run-windows.bat`.
3. Laisser la fenêtre noire ouverte.
4. Ouvrir `http://localhost:8080`.

Comptes de démonstration :
- Administrateur : `admin` / `admin123`
- Bénévole : `benevole` / `benevole123`

Pour utiliser l’appareil photo sur un téléphone, ouvrir MyTree depuis le navigateur du téléphone et autoriser l’accès à la caméra.
